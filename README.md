# Hidden USB Copier

Automatically copies all files from a USB drive to `C:\USB_Backup` when plugged in.

## Usage
1. Run `Start_USB_Backub.bat`
2. Plug in your USB — backup starts automatically
3. Log file: `C:\USB_Backup\USB_Backup_Log.txt`

## Requirements
- Windows 10/11
- PowerShell 5.1+
- No admin rights required

## Note
Runs silently in the background, no window will open.
